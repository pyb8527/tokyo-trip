이 페이지는 구글 지도 위에 핀·반경·동선을 직접 그립니다. 그러려면 Maps JavaScript API 키가 필요해요. 키는 브라우저에만 저장되고 어디로도 전송되지 않습니다.

  1. Google Cloud Console에서 프로젝트 생성
  2. Maps JavaScript API 사용 설정
  3. 사용자 인증 정보 → API 키 만들기
  4. 키 제한: HTTP 리퍼러 + Maps JavaScript API 전용
